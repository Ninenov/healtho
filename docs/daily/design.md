
# HealthOS – Design Guidelines

## Design Philosophy

HealthOS should feel:
- Clean
- Professional
- Trustworthy
- Fast
- Accessible
- Minimal

Healthcare professionals should find information within a few clicks, while patients should feel comfortable even if they are not tech-savvy.

---

# Design Principles

- Simplicity over complexity.
- Consistent layouts across all products.
- Prioritize readability over decoration.
- Mobile-first responsive design.
- Accessibility (WCAG AA where possible).
- High contrast and clear typography.
- Use whitespace generously.
- Never hide critical medical information.

---

# UX Rules

- Maximum 3 clicks to reach key information.
- Always show loading and error states.
- Confirm destructive actions.
- Autosave long forms.
- Keep navigation consistent.
- Display timestamps for medical events.
- Highlight allergies and critical alerts.

---

# Responsive Breakpoints

- Mobile: <768px
- Tablet: 768–1023px
- Desktop: 1024px+
- Large Desktop: 1440px+

---

# Accessibility

- Keyboard navigation
- Screen reader support

- Visible focus indicators
